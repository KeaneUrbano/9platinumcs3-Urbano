### SG4 - Understanding Classes and Objects
# Class Name
Footballer

# Class Description
A footballer can range from a amateur to a professional. They aren't artist in a traditional sense but they make the sport look like art.
T

# Properties
| Properties  | Data Type | Description |
|-------------|-----------|-------------|
| Name  | String  | What the objects name is |
| Age   | Integer | How old the object is    |
| Position | String | What position object plays/comfortable at |
| Nationality | String | What descent object is from |
| Overall Rating | Integer | How good an object is on a scale of 1-100 |
| Height | Integer | How tall an object is | 
| Playstyle | String | How they play like(ex. Trickster, Swift, Shooter)|

## Methods
| Method | Description |
|--------|-------------|
| Run | Begins running |
| Dribble | Drive forward with the ball or backward |
| Pass | Passes to a teammate |
| Shoot | Takes a shot at enemy goal |

## Design Explanation
### Why did you choose this class?
I love playing football, I play it myself and I love the sport with all my heart.

### Which property is the most important? Why?
I believe it is Overall Rating as it shows the attributes the player has, it dictates how good a player is at certain stats(ex. 99 speed, 99 drib etc.). Without Overall Rating a player would have default stats making him trash.

### Which method is the most useful? Why?
For me I believe it is passing, as it helps teams control the tempo, keep possession, and place the ball where they want to place it leading to control. Passing is a form of both defending and attacking.
